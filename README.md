# final-fantasy.fr

## Build statique

```sh
npm install
npm run build
```

Le site utilise Eleventy. Les fichiers source (images et audio) sont dans `resources/`. Le site statique deployable est genere dans `dist/`, qui est ignore par Git. Publiez le contenu de ce dossier avec n'importe quel hebergeur de fichiers statiques.

Pour le previsualiser localement :

```sh
npm start
```
